## 🚀 Quick Commands

```bash
# Development
pnpm dev              # Run all services
pnpm dev:web          # Run only web app
pnpm dev:api          # Run only API

# Formatting & Checks
pnpm format:web       # Format web app
pnpm format:api       # Format API
pnpm check:web        # Check web app (no fix)
pnpm check:api        # Check API (no fix)
pnpm -r typecheck     # Type check all packages

# Build
pnpm build:web        # Build web app
pnpm build:api        # Build API (Bun compile)

# Database
pnpm dk generate      # Generate migrations
pnpm dk push          # Push schema to PostgreSQL
pnpm seed             # Seed sample data
```

## 📁 Project Structure

```
apps/
  ├── api/                    # Elysia backend (Bun + Drizzle + Better Auth)
  │   └── src/
  │       ├── modules/        # Feature modules (agents, auth, knowledge-base)
  │       ├── db/             # Database + schemas
  │       └── lib/            # Utilities (auth, helpers)
  └── web/                    # React Router + Tailwind frontend
      └── app/
          ├── routes/         # Page routes
          ├── store/          # Zustand stores
          └── lib/            # API clients + utils
```

## ✅ Before Writing Code

1. Check [AGENTS.md](./AGENTS.md) for the relevant pattern
2. Ensure you're in the correct package (`api` or `web`)
3. Follow the import organization rules (external → internal aliases → relative)
4. Add proper TypeScript types (no `any` without suppression)
